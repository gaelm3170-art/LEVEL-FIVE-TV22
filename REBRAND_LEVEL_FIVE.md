# LEVEL FIVE TV — OwnTV-based build

This project is a modified build derived from the OwnTV project.

## Branding changes
- App name: LEVEL FIVE TV
- Application ID: `com.levelfive.tv`
- Custom LEVEL FIVE TV logo, launcher icon, TV banner, and splash branding
- Default accent switched to blue
- Visible OwnTV branding in Android string resources replaced with LEVEL FIVE TV branding
